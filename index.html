Skill-Combination Assessment in Interviews

Describe a role as the tasks it involves, how much time each takes, and which skills each task needs (yes or no). The page builds the network of skills the role uses together. Two skills are linked when at least one task needs both. A link's strength adds up the share of the week for every task that needs both skills, so it grows with the number of tasks the two skills share and with the time those tasks take.
